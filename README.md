Engineering Unit Converter

Project Description

The Engineering Unit Converter is a Python program that converts measurements between different units, including length, temperature, mass, and speed.

Features

- Converts millimetres and inches.
- Converts Celsius and Fahrenheit.
- Converts kilograms and pounds.
- Converts km/h and m/s.
- Stores previous conversions in a history list.
- Handles invalid inputs.

My Own Idea

I added a conversion history feature that allows users to view previous results.

What I Learned

I learned how to use Python functions, loops, conditional statements, lists, and error handling to solve a practical engineering problem.

How to Run

Run "engineering_unit_converter.py" using a Python interpreter and follow the menu instructions.
